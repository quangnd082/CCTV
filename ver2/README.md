# EHS CCTV Monitoring (ver2)

Phiên bản ứng dụng có tab **Monitor** + **Settings** và file `settings.json`.

**Hướng dẫn sử dụng đầy đủ:** xem [README.md](../README.md) ở thư mục gốc project.

## Chạy nhanh

```powershell
cd D:\2025\CCTV\ver2
python Program.py
```

## File cấu hình trong thư mục này

| File | Vai trò |
|------|---------|
| `config_data.json` | Danh sách camera (URL, model, rule detect) |
| `settings.json` | Camera hiển thị trên Monitor (lưu từ tab Settings) |
| `config_data_log.json` | Panel ảnh cảnh báo |
